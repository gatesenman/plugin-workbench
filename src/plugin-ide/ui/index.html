      上手指南

      1. 一句话描述需求：写明宿主软件（如 Blender、飞书、公司自研系统「XX」），未知宿主会自动扩展适配器。
      2. 审阅方案：修改项目名 / 功能点；右侧是这个软件的插件须知（技术细节已折叠），AI 生成时会自动遵守。
      3. 看 AI 干活：生成 → 构建 → 失败自动诊断修复（可设上限），每一步都可见；每次 AI 写盘前都有检查点，可随时撤销。
      4. 迭代与发布：在结果卡片或右侧 AI 助手继续对话；满意后打包并生成发布清单。

      进阶：左侧「厂商目录」浏览 700+ 宿主，「生命周期」手动执行各阶段，「设置」接入 OpenAI 兼容模型（默认离线 Mock）。
